# Blood Bank Management

**University project, 2021** · Java, pre-Compose Android

A donor registry connecting people who need blood with people willing to give it.

---

## Screens

| Screen | Purpose |
|---|---|
| `Sign_Up_Act` / `Sign_in` | Account creation and authentication |
| `Search_Donor` | Find donors by blood group and location |
| `Donait_Blood` | Register as a donor |
| `Donor_Data_contact` | Donor details and contact |
| `User_profile` | Manage your own record |

## Why it is still listed

It is five years old and written in Java before Jetpack Compose existed, so it is not a sample of current work. It is here because it was a complete application rather than an exercise — authentication, a search flow over real records, and a two-sided model where the same person can be both donor and requester.
